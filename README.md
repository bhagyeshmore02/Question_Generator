# 🤖 AI Question Generator

An AI-powered Question Generator that uses **Google Gemini** and **Gradio** to generate questions from study material.

## 📌 About the Project

The AI Question Generator allows users to paste study material or any educational content and generate different types of questions using Google's Gemini AI.

### Available Question Types

- 📝 **MCQs** – Multiple-choice questions with 4 options and the correct answer
- ✍️ **Short Answer** – Short-answer questions based on the provided content
- 🎤 **Interview** – Interview-style questions based on the provided content

---

## ✨ Features

- Generate AI-powered questions
- Multiple question types
- Simple and user-friendly interface
- Powered by Google Gemini
- Built with Python and Gradio
- Hosted online using Render

---

## 🛠️ Tech Stack
